# CaseClosed Extension Template

This is the official CaseClosed Extension template.

It demonstrates:

- reading the launch context
- reading the selected Case
- listing Case files
- querying CaseClosed mails with filters
- uploading a generated CSV back to the selected Case

Register path:

```text
extensions/caseclosed-extension-template/caseclosed-extension.json
```

When CaseClosed starts, this manifest is registered automatically as a default Extension.
